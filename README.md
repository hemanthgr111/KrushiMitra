# KrushiMitra – Multilingual Agricultural Social Networking Mobile Application

## Project Objective
KrushiMitra is a professional agricultural mobile application for Android and iOS that combines agricultural management tools, AI assistance, and social networking for farmers.

## Technology Stack
| Layer | Technology | Purpose |
| :-- | :-- | :-- |
| Mobile | React Native + Expo + TypeScript | Cross-platform mobile application |
| Backend | Java 21 + Spring Boot | REST APIs and business logic |
| Database | PostgreSQL | Relational data storage |
| AI Service | Python + FastAPI | AI and ML orchestration |
| Local AI | Ollama with an open-source model | On-device/private AI assistance |
| Coding Assistant | OpenCode AI | Development workflow support |

## Supported Languages
KrushiMitra supports exactly the following nine languages:
- English
- Kannada
- Hindi
- Telugu
- Tamil
- Malayalam
- Marathi
- Bengali
- Gujarati

## Major Features

### Agriculture
- Farm management
- Soil records
- Crop management
- Crop recommendations
- Fertilizer guidance
- Crop disease detection
- AI agricultural chatbot
- Weather information
- Market prices
- Government schemes

### Social Networking
- Farmer profiles
- Posts and image uploads
- Likes and comments
- Follow and unfollow
- Search
- Hashtags
- Bookmarks
- Notifications
- Reporting and blocking
